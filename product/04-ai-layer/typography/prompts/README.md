# Typography prompts

Four prompts for AI tools working with ds typography. Each is a ready-to-paste block with a short "what good looks like"
section, so the person using it can tell a good answer from a bad one.

| Prompt | Use it to | The AI must… |
|---|---|---|
| [Build with type](build-with-type.md) | build a screen or component | plan a style for every piece of text first, keep heading tags in outline order, write code with styles only |
| [Review type use](review-type.md) | review code or a design before it ships | confirm the checker's findings and find what a checker can't: inherited sizes, fake headings, text that breaks at 200% or with the spacing override |
| [Add a text style](add-a-text-style.md) | handle "we need a new size" | look for an existing style first; if none fits, propose one in engine config the build can compute and check |
| [Theme the type](theme-type.md) | adopt ds with a brand font or a different scale | set up the config and run the engine; quote numbers only from its output |

## Always attach the rulebook

Every prompt expects `../typography.md` — the typography rulebook generated by the engine — in the same chat. It holds the
rules (TR-01 … TR-14), the decision guide, every style with its size and line height at each breakpoint, what `tokens.css`
already does, and the measured common mistakes. For tools that handle JSON well, `../typography.contract.json` has the same
content in machine-readable form.

Most screens use colour too: attach `../../color/color.md` as well when the work involves colour.

Regenerate both whenever tokens change (`npm run build && npm run publish` in the engine folder). An AI working from an
old rulebook will pick styles that no longer exist.

## Trust, but check

An AI's answer is a draft. Each prompt names the tool that checks it:

- **Code** → `npm run lint:type -- <files>` reads the source; `npm run audit:type -- <page.html>` renders it at desktop and 320px, with 200% text and the WCAG text-spacing override, and measures what readers get.
- **New styles and fonts** → `node src/cli.js <config.json> out/<name>`. The engine computes every size and runs every typography check; it stops if one fails.

See [../tests/](../tests/README.md) for how these prompts were tested and how to test them with your own tool.
