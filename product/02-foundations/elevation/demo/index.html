Projects

Cards are raised. Hover one: the fill changes as well as the shadow. Each card's menu is a popover: it sits in the browser's top layer, so a card or a table that clips its content (overflow: hidden) can never cut it off, and it is above the sticky header without a z-index.

A dialog

A <dialog> opened with showModal(): the scrim, the edge and the top layer come with .ds-modal; the page behind is inert, Escape closes it and focus goes back to the button. The menu inside the dialog is a popover too, so it opens above the dialog.

Reorder

Drag an item by its grip: while it is held it takes .ds-dragging, above everything, and goes back when dropped. Dragging is never the only way: the move buttons do the same with a click or the keyboard.
